# תוכנית לעדכון עמוד הספר החדש

## מטרה
לארגן מחדש רק את `/book-new` כמשפך תוכן והזמנה ברור, תוך שמירה מלאה על מעטפת האתר, נתוני המטא, הסימון המשפטי, הנגישות והזמנה דרך WhatsApp בלבד.

## שינויים בעמוד
- לסדר את התוכן בתוך `main#content` כך שיופיע: פתיח, סיפור פותח, ברכות הרבנים, שלושה סיפורים, קטע לקריאה, תוכן הספר, על עמיחי והמיזם, הזמנה, שאלות ותשובות ומדיניות ביטול.
- לעדכן את כותרת הפתיח, טקסט המשנה, המחיר, הכפתורים ושורת המשלוח בדיוק לפי הנוסח שנמסר.
- להחליף את מפרט הספר בפתיח ברצועת אמון בת ארבעה נתונים מתחת לאזור הפתיח.
- להוסיף את סקשן ״הסיפור שפותח את הספר״ עם הציטוט והקישור לקטע הקריאה.
- להעביר את ברכות הרבנים מיד אחרי הסיפור הפותח, לשמור את שלושת המכתבים והקישורים הקיימים, ולהוסיף את שלושת קישורי ההמשך שנדרשו.
- להעביר את כפתור ההזמנה גם לעמודת המבוא של קטע הקריאה.
- למזג את תוכן ״על הספר והמיזם״ לתוך ״על עמיחי״ ולמחוק את הסקשן הנפרד.
- לעדכן את כותרת ההזמנה, ההסבר, מחיר ליחידה המחושב מכל מארז, טקסט הסיכום ותווית כפתור WhatsApp, בלי לשנות את המספר או את לוגיקת ההודעה.
- להוסיף פס הזמנה דביק במובייל שמציג את המארז הנבחר, הסכום הכולל והפניה לאזור ההזמנה.
- לעדכן את ניווט ״בעמוד הזה״ לסדר הקישורים המבוקש.

## עיצוב ונגישות
- להוסיף עיצוב ממוקד לרצועת האמון, לסיפור הפותח, לאזור ברכות כהה, לכרטיסי הרבנים, למחיר ליחידה ולפס המובייל.
- להשתמש רק בצבעים ובפונט שהוגדרו, עם פריסה דו-עמודתית שמתכנסת היטב במובייל.
- לשמור `scroll-margin-top: 100px`, מצבי `focus-visible`, RTL, תוויות נגישות והעדפת הפחתת תנועה.
- להשאיר מרווח תחתון במובייל כדי שהפס הדביק לא יסתיר את סוף העמוד או את הפוטר.

## גבולות העבודה
- לערוך רק את `src/routes/book-new.tsx` ואת `src/book-new.css`.
- לא לשנות את ה-Header, הפוטר, עמודים אחרים, meta, JSON-LD, noindex או נוסחי מדיניות הביטול.
- לא לפרסם ולא להעלות לפרודקשן.

## אימות
- לבדוק טיפוסים ואת תוצאת הבנייה.
- לפתוח את `/book-new` בדסקטופ ובמובייל, לבדוק את סדר התוכן, העוגנים, בחירת המארז והמשלוח, עדכון הסכום והפס הדביק.
- לוודא שאין שגיאות קונסול או גלישה אופקית במובייל.
